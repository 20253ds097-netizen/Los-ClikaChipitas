# UI_T10 - Proyecto en Equipo

Este repositorio contiene el desarrollo de la práctica UI_T10, realizada de manera colaborativa. El objetivo del proyecto es estructurar un sitio web básico que unifique las páginas individuales de los integrantes del equipo, aplicando control de versiones con Git y despliegue a través de GitHub Pages.

## Características del Proyecto

El sitio web está compuesto por las siguientes secciones y páginas:

* **Página Principal (index.html):**
    * Título con el nombre del equipo.
    * Logotipo del equipo (diseño propio).
    * Lista ordenada con los nombres de los integrantes.
    * Tabla informativa que contiene: matrícula, sexo, edad y un enlace directo a la página individual de cada integrante.
* **Sección de Integrantes:** Páginas individuales (TuMatricula.html) personalizadas por cada miembro junto con una imagen propia (foto o meme).
* **Página de Error (404.html):** Una página de error personalizada para manejar rutas no encontradas dentro del sitio.
